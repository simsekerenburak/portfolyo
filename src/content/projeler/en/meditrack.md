An end-to-end medication tracking system:

- Arduino-based physical reminder (LCD + buzzer)
- Python/customtkinter desktop app
- FastAPI backend (on Render)
- Firebase/Firestore data layer
- A PWA added to the iPhone home screen, with real-time push notifications

The code is on GitHub: github.com/simsekerenburak
